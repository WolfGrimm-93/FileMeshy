# Frontend

Parte de [Estándares Cliente-Servidor 2026](index.md)

## Checklist
- [ ] Responsive real (mobile-first, no solo "que no se rompa")
- [ ] Accesibilidad (WCAG 2.2 AA como mínimo)
- [ ] Manejo de estado predecible (loading, error, empty, success en cada vista)
- [ ] Optimización de rendimiento (lazy loading, code splitting, imágenes optimizadas)
- [ ] Soporte offline/degradado cuando aplique (PWA, service workers)
- [ ] Internacionalización (i18n) si el público lo requiere
- [ ] Dark mode
- [ ] Feedback claro al usuario (toasts, skeletons, validación en tiempo real)
