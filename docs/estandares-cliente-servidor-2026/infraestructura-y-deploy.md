# Infraestructura y Deploy

Parte de [Estándares Cliente-Servidor 2026](index.md)

## Checklist
- [ ] Contenerización (Docker) y orquestación reproducible
- [ ] Entornos separados (dev/staging/prod) con paridad razonable
- [ ] Rollback rápido ante fallos de deploy
- [ ] Backups automáticos y probados (restore real, no solo "se hace backup")
- [ ] Escalabilidad horizontal (stateless donde se pueda)
- [ ] CDN para assets estáticos
